## Acceptance criteria
1. 60 s offline render with synthetic inputs: no clipping, zero underruns, ducking curve verified numerically.
2. Shuffle reproduces from seed; resume position correct across switches; state machine tested table-style.
3. Engine pitch tracks RPM; shift pops; WAV hash pinned; synth cost ≤ 0.3 ms per 256-sample block.
4. In headless Chromium: worklet starts after a user gesture simulation, ring buffer stays fed for 30 s (test page); file picker path unit-tested with a generated WAV.
5. Native: generated WAV decodes through the full path; a local Icecast-like HTTP test server (in the test) streams MP3 bytes with ICY metadata and titles arrive.
6. Gamepad-navigable stations manager; persistence round-trip.
7. Every preset URL checked by the script at commit time; no audio in repo; names/URLs only.
8. Screenshot of the dash with station text; report.
